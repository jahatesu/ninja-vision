# Ninja Vision Architecture

Ninja Vision is a real-time computer vision web application
that recognizes hand gestures and hand-seal sequences and
renders corresponding visual effects.

## Major Systems

1. Hand Tracking
2. Gesture Recognition
3. Jutsu Sequence Recognition
4. Body / Face / Hand Tracking
5. Visual Effects Engine
6. Web Application
7. Backend API
8. Database
